## Part 1 — Discrete Fourier Transform (1 mark)

Builds a square wave from a truncated Fourier series of odd harmonics, decomposes it back into
frequencies with a naive O(N²) DFT and compares against `torch.fft.fft`, then ports everything to
PyTorch with a GPU DFT implementation and times naive-DFT-CPU vs naive-DFT-GPU vs FFT across
signal sizes.

## Part 2 & 3.1 — Eigenfaces and CNN (2 marks)

PCA ("eigenfaces") + random forest vs a from-scratch CNN, both on the LFW faces dataset.

| model | test accuracy |
|---|---|
| PCA (150 components, 94.7% variance) + random forest | 0.606 |
| CNN (2 conv layers, 3x3/32 filters, dense head) | 0.857 |

## Part 3.2 — DAWNBench ResNet-18 on CIFAR-10 (4 marks)

ResNet-18 built from scratch (residual blocks, CIFAR stem — no ImageNet-style 7x7/maxpool),
trained with SGD + OneCycleLR, evaluated with and without mixed precision (AMP).

| run | epochs | time | best test acc |
|---|---|---|---|
| FP32 | 30 | 211.8s | **0.9360** |
| AMP  | 30 | 187.1s | 0.9339 |

- \>90% in <30 min: **met** (93.6% in 3.5 min)
- 94% in ≤360s (DAWNBench stretch, A100 vs the reference V100): time met (187.1s), accuracy short
  (93.39%)

Staged notebook (`part3_dawnbench.ipynb`): architecture sanity check → smoke test → full FP32 run →
AMP run → per-class results, each gated by an env var so cheap stages can run alone. Live-demo
command (1 epoch, no retrain of the full run):

```bash
DAWN_EPOCHS=1 DAWN_STAGE4=1 DAWN_STAGE3=0 jupyter nbconvert --to notebook --execute --inplace part3_dawnbench.ipynb
```

## Part 4 Task 1 — Variational Autoencoder on OASIS (up to 3 marks)

Convolutional VAE (encoder → mu/logvar → reparameterisation → decoder), trained on OASIS brain MR
slices, with both accepted manifold visualisations: a decoded 2D grid sweep and a t-SNE scatter of
encoded test images (UMAP unavailable — Rangpur compute nodes have no internet to install it).

Three runs, exploring the resolution/latent-dimension tradeoff:

| run | resolution | latent dim | final val KL | epochs | time |
|---|---|---|---|---|---|
| `vae_outputs` | 64x64 | 16 | 8.98 | 30 | 156s |
| `vae_big` | 128x128 | 32 | 32.34 | 30 | 174s |
| `vae_latent2` | 64x64 | 2 (direct-sweep manifold) | 3.92 | 30 | 161s |

No run's KL collapses to ~0 — no posterior collapse.

## Part 4 Task 2 — UNet segmentation of OASIS (+2 marks)

UNet (concatenating skip connections, categorical/one-hot 4-class output), trained with a combined
Dice + cross-entropy loss to counter severe class imbalance (background ≈72% of pixels).

| class | test DSC |
|---|---|
| 0 background | 0.9995 |
| 1 CSF | 0.9521 |
| 2 grey matter | 0.9517 |
| 3 white matter | 0.9726 |
| **mean / min** | **0.9690 / 0.9517** |

**All four labels clear the 0.9 requirement.** 25 epochs, 377s. Live-demo command (inference only,
no retraining, loads the existing checkpoint):

```bash
UNET_STAGE2=0 UNET_STAGE3=0 UNET_STAGE4=1 UNET_STAGE5=1 jupyter nbconvert --to notebook --execute --inplace part4_unet.ipynb
```

## Part 4 Task 3 — WGAN-GP brain generation on OASIS (+2 marks)

WGAN with gradient penalty (Wasserstein critic, no BatchNorm in the critic, 5 critic steps per
generator step), 100 epochs at 64x64. Mode collapse is checked four independent ways, not asserted:

| check | result |
|---|---|
| 8x8 grid of independent samples | visibly diverse |
| nearest-neighbour to training set | mean L2 distance 7.73 (not memorised) |
| diversity ratio (generated vs real) | 0.94 |
| latent interpolation | smooth morph, no discontinuities |

Final Wasserstein estimate 2.17 (down from 70.5), final gradient penalty 0.023 (stable). 100
epochs, 492s.

## Running on Rangpur

Each `run_*.sh` mirrors its notebook's Python config as `${VAR:-default}` environment variables, so
any value can be overridden at submission time without editing the script, e.g.:

```bash
sbatch --export=ALL,GAN_EPOCHS=200 run_gan.sh
```

All four SLURM scripts use `--partition=comp3710 --account=comp3710 --gres=gpu:1` (no `--mem` — the
partition rejects it) and the conda env at `./pytorch-env`. See the comment block at the bottom of
each script for the matching smoke-test and live-demo command lines.
